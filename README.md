Project Overview

The Event Hall Management System is a software application designed to simplify and automate the process of managing event hall bookings, customer details, payments, and event scheduling. This system helps administrators efficiently manage reservations while providing customers with a smooth booking experience.

The project aims to reduce manual work, prevent booking conflicts, and maintain accurate records of events and payments.

 Features
 User Features

View available event halls

Check availability by date and time

Book event hall

View booking history

Secure login and registration

Online payment (if integrated)

 Admin Features

Add, update, or delete event halls

Manage bookings

Approve or reject reservations

Generate booking reports


System Modules

Authentication Module

User registration

Hall Management Module

Booking Management Module

Booking reports

Revenue reports
