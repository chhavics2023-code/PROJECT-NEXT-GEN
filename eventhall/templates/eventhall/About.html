About Event Hall Management System

The Event Hall Management System is a web-based application designed to simplify the process of booking and managing event halls online.

This system allows users to:

  • Browse available event halls
  • View hall details and images
  • Submit online booking requests
  • Track booking status (Pending / Approved / Rejected)

From the administrator side, the system provides features to:

  • Manage event hall listings
  • Approve or reject booking requests
  • Monitor bookings through an admin dashboard

This project is developed using Django, HTML, CSS, Bootstrap, and JavaScript, making it suitable for educational and real-world applications.
